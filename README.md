## Project Description

This project develops a RESTful Accounts microservice as part of the IBM DevOps Capstone Project.

## Objectives

- Develop and test REST API endpoints for account management.
- Use GitHub for source control and collaboration.
- Automate continuous integration using GitHub Actions.
- Apply security headers and CORS policies.
- Containerize the application using Docker.
- Deploy the application using Kubernetes and automate delivery using Tekton.

## Technologies

Python, Flask, REST APIs, GitHub Actions, Docker, Kubernetes, and Tekton.
